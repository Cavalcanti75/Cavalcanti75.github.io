# Portfólio — Desenvolvedor Full Stack

Portfólio pessoal de **Nataly Barros Cavalcanti**, profissional em transição de carreira para Desenvolvimento Full Stack, trazendo consigo 10 anos de experiência em Design Gráfico.

🔗 **Acesse o site:** [cavalcanti75.github.io](https://cavalcanti75.github.io)

## 📋 Sobre

Site desenvolvido para apresentar minha trajetória profissional, habilidades técnicas, certificados e formas de contato de forma organizada e moderna, com suporte a modo claro/escuro (dark mode automático).

## ✨ Funcionalidades

- **Navegação por abas**: Sobre, Skills, Certificados, Experiência e Contato
- **Filtro de certificados** por instituição (Faculdade, Alura, Senai, Udemy, Outros)
- **Dark mode** automático, baseado na preferência do sistema (`prefers-color-scheme`)
- **Design responsivo**, adaptado para dispositivos móveis
- **Links diretos** para e-mail, LinkedIn e GitHub

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (variáveis CSS, layout responsivo, media queries)
- JavaScript (vanilla — troca de abas e filtros)
- Google Fonts (DM Serif Display e DM Sans)
